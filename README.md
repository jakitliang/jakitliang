# Hi, I'm Jakit 👋

### Systems-minded developer building lightweight runtimes, Lua libraries, graphics tools, and cross-platform software.

I enjoy working close to the runtime—designing small, expressive APIs and connecting **C/C++ performance** with the flexibility of **Lua**. My projects explore language implementation, native bindings, networking, data modeling, graphics, and game-development foundations.

## 🚀 Featured Projects

| Project | What it is | Technical highlights |
| :--- | :--- | :--- |
| **[Lumen](https://github.com/jakitliang/lumen)** | A modernized and refined Lua interpreter designed for current operating systems and compilers. | C++17 · Lua 5.1 compatibility · VM/runtime architecture · bytecode compiler · handle-based native interface · embedding |
| **[Light.lua](https://github.com/jakitliang/Light.lua)** | A full-stack Lua toolkit spanning application, backend, networking, data, and UI concerns. | Lua/LuaJIT · prototype objects · ORM · coroutines/event loop · HTTP/WebSocket · TCP/UDP · LÖVE-compatible graphics |
| **[Choco.cpp](https://github.com/jakitliang/Choco.cpp)** | A compact C++ framework focused on game-development foundations and data-oriented design. | Modern C++ · data-oriented design · engine architecture · reusable native components |
| **[Socket.lua](https://github.com/jakitliang/Socket.lua)** | A small cross-platform native socket layer for building higher-level Lua networking systems. | C++ · Lua bindings · TCP/UDP · non-blocking I/O · socket selection · Windows/Linux/macOS/iOS |
| **[Object.lua](https://github.com/jakitliang/Object.lua)** | A performance-minded prototype-oriented object system designed around Lua's strengths. | Lua metatables · prototype inheritance · mixins · reflection · operator overloading · method caching |
| **[Record.lua](https://github.com/jakitliang/Record.lua)** | A lightweight ORM-style data layer for Lua applications and games. | Lua · CRUD · transactions · ActiveRecord-style models · SQLite-oriented workflows |
