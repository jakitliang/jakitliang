## About Me

I focus on building performant, embeddable systems around **Lua and C++**, including interpreter/runtime work, networking modules, and graphics-oriented components.

我主要专注于 **Lua + C++** 的底层能力建设：解释器/运行时、网络模块、以及图形与引擎相关组件。
